    How it works

    The tree is simulated once as a skeleton of nodes. Time is a render parameter, so scrubbing never re-runs the simulation. Every random choice comes from a hash of the seed, bud, step and channel, so the same settings reproduce the same tree. Cuts are stored as stable budId:birthStep keys; pruning re-simulates light so nearby branches can respond. The 2D silhouette and 3D form share a seed, parameters, cuts and time, but use separate simulation and render engines.

    Reset app state?

    This clears both views, cuts, the saved session, mode/layout, Record settings and view options. Onboarding will not replay. This cannot be undone.
