    How it works

    The tree is simulated once as a skeleton of nodes. Time is a render parameter, so scrubbing never re-runs the simulation. Every random choice comes from a hash of the seed, bud, step and channel, so the same settings reproduce the same tree. The 2D silhouette and 3D form share a seed, parameters and time, while using separate rendering engines.
